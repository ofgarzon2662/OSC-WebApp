Why provenance changes the record

Storage preserves a file. OSC-IS preserves its context.

OSC-IS uses Hyperledger Fabric as a permissioned provenance layer. Research files remain off-chain. The shared record contains their fingerprints, responsible organization, contributor, workflow relationships, and accepted changes.

Question File storage OSC-IS record
What was preserved? The current file File fingerprint and manifest
Who accepted it? May depend on local logs Contributor and organization
How was it produced? Stored separately Linked workflow and source revision
What changed? Previous state may be replaced Each accepted revision remains inspectable
